# Clone Medium3

This project is a simple clone of the **Medium** homepage, created using **HTML**, **CSS** (with **Bootstrap**), and without JavaScript.

## Features

- **Responsive Design:** The page is designed to be responsive, adapting to different screen sizes.
- **Headlines & Categories:** The homepage includes various articles and categories, mimicking the Medium layout.
- **Modern UI:** The design replicates the visual style of Medium with a clean and user-friendly interface.
