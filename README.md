Clone Medium3
This project is a simple clone of the Medium homepage, created using HTML, CSS (Bootstrap), and without JavaScript.

Features
Responsive Design: The page is designed to be responsive, adapting to different screen sizes.

Headlines & Categories: The homepage includes various articles and categories.

Modern UI: The design mimics the visual style of Medium with a clean and user-friendly interface.
